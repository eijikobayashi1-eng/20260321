## 全体構造

```
大野社長 ＋ コルトスタッフ（人間）… 監修・方針判断・LoRAデータ提供・品質修正・承認判断
  │
  ├─ INPUT00（Step 0）顧客情報収集 ─→ STORY・WF1・各チームへ配布
  │
  └─ MANGA00 漫画制作管理（オーケストレーター）
        INPUT00 → STORY → 制作承認 → VISUAL → CSP を順次起動・管理
        チーム間の連携制御・品質判断・差し戻し判定。
        「どの成果物を、いつ、どこにつなぐか」を状況に応じて判断する
        （例: キャラ画像を1〜2枚作ってから WF1 に組み込む）
```

|---|---|---|---|
| — | **MANGA00** | オーケストレーター | Claude（Sonnet） |
| — | **INPUT00** | 顧客情報収集（クライアント基本情報 / ニーズ・課題 / テーマ・ジャンル / ターゲット読者 / 予算・スケジュール / 参考スタイル） | Claude |
