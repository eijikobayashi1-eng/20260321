🧭 MANGA00（オーケストレーター）の役割
MANGA00は各チームの成果物を把握し、状況に応じて次にどのエージェントにつなぐかを判断する司令塔です。
たとえば「ネームが完成したら即WF1へ」という場合もあれば、キャラクター画像・世界観ビジュアルを1〜2枚作成してからWF1（営業提案書）に組み込むという判断もあります。 WF2（稟議承認書）でも同様に、ビジュアルを多数掲載した上で稟議に回すこともあります。
どのチームの成果物を、いつ、どこにつなぐか ── この柔軟な判断ができることが、AIエージェントチームを編成する最大の価値です。

─── 同じAIを使っても、なぜコルトは違うのか？ ───

😐 素人がAIを使った場合
  • ✗顧客情報収集が曖昧なまま制作スタート → 方向性がズレる
  • ✗LoRA学習なし → 画風がページごとにバラバラ
  • ✗稟議なしで着手 → 後から上司NGで全やり直し
  • ✗修正が次に活かされず毎回同じ品質
  • ✗AIが出した画をそのまま使う（画一的）
⭐ コルトのAIエージェントの場合
  • ✓MANGA00がStep 0でINPUT00を起動 → 顧客情報を整理してから全工程がスタート
  • ✓LoRA学習 → コルト固有の画風を全ページ維持
  • ✓WF2で稟議資料を事前作成 → やり直しゼロを目指す
  • ✓プロの修正が積み重なり精度・品質が向上する
  • ✓プロが監修・修正し「コルトらしさ」を守る

─── コルトが差別化できる 3つの理由 ───

REASON 01
📚
何をどう学習させるか
LoRAに「何を覚えさせるか」はコルトの固有資産。キャラ・背景・画風の組合せは会社ごとに異なる独自ナレッジになり、他社には再現できない。
REASON 02
⚙️
どのAIをどう組み合わせるか
Claude × Anifusion × CSPマクロの組合せはコルト独自の設計。スキルを積むほど他社が真似できない体制になる。
REASON 03
🔄
修正をプログラム化して蓄積する
「この絵はこう直す」という判断を繰り返すことでプロンプトやマクロに蓄積。プロのスキルが会社の財産になっていく。
