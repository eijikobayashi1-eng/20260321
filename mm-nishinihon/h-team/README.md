# Hチーム 受発注・在庫管理AIエージェント（エムエム西日本 宅配事業部）

DMM D2「商品・在庫管理」①需要予測・発注量設定 ②メーカー発注 を対象とした Phase 1 エージェント。
Google スプレッドシート ＋ Google Apps Script（GAS）で動作し、サーバーや追加費用は不要。

## 処理フロー

```
H00 司令塔（毎日定時に起動）
  └ H01 在庫検知 → H02 発注量計算 → H03 発注書作成 → 👤社長承認 → H04 メール送信
```

| ワーカー | 状態 | ファイル |
|---|---|---|
| H00 司令塔 | 骨組みのみ（H01 を呼び出す） | `src/H00_Orchestrator.gs` |
| H01 在庫監視 | **実装済み・確認待ち** | `src/H01_InventoryMonitor.gs` |
| H02 需要予測・発注量計算 | 未着手 | — |
| H03 発注書作成 | 未着手 | — |
| 👤 社長 最終承認 | 未着手（H03 と一緒に作成） | — |
| H04 発注メール送信 | 未着手 | — |

## シート構成

「発注候補」シートが各ワーカーの受け渡し場所。1商品＝1行で、ステータス列が工程を表す。

| シート | 内容 | 書き込むワーカー |
|---|---|---|
| 在庫 | 商品コード・商品名・メーカーコード・現在庫数・発注基準値・単位・発注対象 | 人（既存運用） |
| メーカーマスタ | メーカーコード・名称・発注方法（メール/FAX/専用システム）・メールアドレス等 | 人 |
| 発注実績 | 過去の発注日・商品コード・数量（H02 が参照） | 人 / H04 |
| 発注候補 | 検知 → 数量計算 → 承認待ち → 承認済 → 送信済 の進行管理 | H01〜H04・社長 |
| 実行ログ | 各ワーカーの実行結果・警告・エラー | 全ワーカー |

ステータス：`検知済`(H01) → `数量計算済`(H02) → `承認待ち`(H03) → `承認済`(社長) → `送信済` / `手動発注要`(H04) → `手動発注済`(担当者)。`取消` はいつでも可。

列名は `src/Config.gs` の `COL` で一元管理しているので、実際のシートの列名に合わせる場合はそこだけを書き換える。

## H01 在庫監視 の仕様

1. 「発注対象」列が `停止`・`対象外`・`×`・FALSE などの商品はスキップ（空欄は対象）
2. **現在庫数 ≦ 発注基準値** の商品を検知し、「発注候補」に `検知済` で登録（不足数＝基準値−在庫）
3. 同じ商品に処理中（送信済・手動発注済・取消 以外）の候補があれば二重登録しない
4. 在庫数・基準値が数値でない、商品コードが空欄・重複している行はエラーとして実行ログに記録し、検知しない
5. メーカーマスタに無いメーカーコードは、検知したうえで備考と実行ログに警告を残す
6. 全角数字・カンマ入り（`１２`、`1,200`）も数値として扱う

## 導入手順（テスト用スプレッドシートで試す）

1. 新しい Google スプレッドシートを作成
2. メニュー「拡張機能 > Apps Script」を開く
3. `src/` の各 `.gs` ファイルを、同じ名前のスクリプトファイルとして作成し中身を貼り付ける
   （`appsscript.json` は「プロジェクトの設定 > 『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにすると編集できる）
4. 保存してスプレッドシートを再読み込み → メニューに「Hチーム」が表示される
5. 「Hチーム > 初期セットアップ」→ 初回は Google の権限確認が出るので許可
6. 「Hチーム > サンプルデータ投入」→「H01 在庫チェックのみ実行」
7. 「発注候補」シートに P001・P003・P005 の3件が登録されれば正常（P007 は停止中なので対象外）
8. もう一度実行しても重複登録されないことを確認

本番運用時は「定期実行を設定（毎日）」で毎朝7時台に自動実行される（時刻は `Config.gs` の `TRIGGER_HOUR`）。

## 第7回（2026-11-16）で確認したい H01 関連事項

- 在庫スプレッドシートの実際の列構成・列名（→ `Config.gs` の `COL.INV` に反映）
- 発注基準値は商品ごとに設定されているか、固定値か
- 判定は「基準値**以下**」でよいか（「未満」にする場合は1行の変更で対応可）
- 在庫数の更新タイミング（毎朝何時に最新になるか → 定期実行の時刻を決める）
- 試入君から在庫スプレッドシートへのデータ連携の有無
- 取り扱い終了・休止商品の扱い（「発注対象」列で管理してよいか）
